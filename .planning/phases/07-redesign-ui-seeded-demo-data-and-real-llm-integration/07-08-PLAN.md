<objective>
Rebuild the F8 review-queue screen on Carbon, using the already-rebuilt
shared state components (07-06) and shell (07-05). The queue's central
accessibility risk in a Carbon rebuild is Carbon's own `DataTable`
component, which ships built-in sortable-column chrome by default — this
product's FR-8.3/phase-criterion-4 explicitly REQUIRES the review queue to
have NO sort control, NO filter, NO assignment affordance anywhere in the
DOM. This plan must use Carbon's plain table PRIMITIVES (`Table`,
`TableHead`, `TableRow`, `TableHeader`, `TableBody`, `TableCell`) composed
by hand with no `isSortable` prop and no `DataTable` wrapper, never the
batteries-included sortable pattern.

Purpose: retire USWDS from the queue table while preserving the "absence is
designed, not omitted" guarantee the current implementation already proves.
Output: `Queue.tsx` rendering on Carbon; `docs/a11y/queue.md` re-signed;
`e2e/queue.spec.ts` updated.
</objective>

<objective>
Rebuild the persistent application shell — `SkipLink`, `Banner` (the U.S.
government official-site banner), `Header`, `Nav`, `Footer`, `LiveRegions`,
and their `Shell` assembly — on Carbon Design System components and tokens,
in place of USWDS. Every structural guarantee F2 requires (exactly one
banner/main/contentinfo, exactly one primary nav with exactly two
destinations, the skip link as the first focusable element, focus
management on navigation, both live regions present from first paint) must
survive unchanged — only the visual system underneath changes.

The government banner has no Carbon equivalent (it is a federal statutory
element Carbon was never designed to include), so its keyboard-operable
disclosure is rebuilt as a documented Carbon-conformant composition: Carbon
`Button`/`Tag`/layout primitives plus a small amount of project-owned React
state managing `aria-expanded`, replacing USWDS's own JS which drove that
toggle until now.

Purpose: deliver the first fully Carbon-rendered surface every screen
inherits, and open the Carbon-equivalent conformance register other plans
append to.
Output: the shell renders on Carbon; `docs/a11y/shell.md` is re-signed
against it; `docs/carbon-conformance-register.md` exists with shell rows;
`e2e/shell.spec.ts` is updated to Carbon's real selectors.
</objective>

**Create `web/src/lib/formatDateTime.ts`** — a pure function both this screen
and Phase 5/6's case-detail screens will reuse (FR-8.14): absolute LOCAL
date+time, month in words, no relative phrasing ("2 days ago" is forbidden
anywhere in this codebase per FR-8.14/UX conventions).

```ts
/** "11 Sep 2026, 14:32" — absolute local date+time, 24-hour clock, month in words. */
export function formatDateTime(iso: string): string {
  const d = new Date(iso);
  const datePart = new Intl.DateTimeFormat('en-GB', {
    day: 'numeric', month: 'short', year: 'numeric',
  }).format(d);
  const timePart = new Intl.DateTimeFormat('en-GB', {
    hour: '2-digit', minute: '2-digit', hour12: false,
  }).format(d);
  return `${datePart}, ${timePart}`;
}
```
(`en-GB` gives "11 Sep 2026" day-month-year ordering and a 24-hour clock
without AM/PM — matching the FRD's example exactly. Do not use the visitor's
browser locale for anything else on this screen; this is the one deliberately
fixed-locale formatting function in the codebase.)
